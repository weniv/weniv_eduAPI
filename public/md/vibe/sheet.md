# 3. 시트로 데이터 보기

---

내 공간 주소 뒤에 `/_sheet`를 붙이면, 저장된 데이터를 **스프레드시트처럼 표로** 볼 수 있습니다. 로그인 없이 누구나 열 수 있습니다.

```python
https://dev.wenivops.co.kr/services/fastapi-crud/vibe/{space}/_sheet
```

## 1. 화면 구성

- **컬렉션 탭**: 시트 탭처럼 컬렉션별로 나뉘어 있고, 탭 옆 숫자는 데이터 개수입니다.
- **표**: 데이터 하나가 한 줄(행), 필드 하나가 한 칸(열)입니다. 새로 저장된 줄은 잠깐 노란색으로 표시됩니다.
- **최근 요청**: 앱이 보낸 요청의 Method·주소·상태 코드·body가 최근 순으로 쌓입니다. 실패한 요청은 빨간 상태 코드로 표시됩니다.
- **JSON 보기**: 같은 데이터를 원본 JSON으로 볼 수 있습니다.
- **발표 모드**: 글자를 크게 키워 프로젝터로 보여주기 좋게 만듭니다.

화면은 3초마다 자동으로 새로고침됩니다.

## 2. 이렇게 보면 공부가 됩니다

| 시트에서 보이는 것 | 알 수 있는 것 |
|---|---|
| 앱에서 '등록'을 누르면 표에 한 줄이 생김 | 데이터베이스는 표, 데이터 하나는 표의 한 줄 |
| 표 ↔ JSON 보기를 번갈아 봄 | JSON 객체 하나가 표의 한 줄과 같다는 것 |
| 최근 요청에 `POST 201`이 찍힘 | 어떤 HTTP 메서드로 무엇을 보냈는지 |
| `name`과 `userName` 열이 따로 생김 | 필드 이름을 맞춰야 하는 이유(스키마) |
| 최근 요청에 `400`이 빨갛게 찍힘 | 서버가 왜 거절했는지 (`detail` 메시지 확인) |
