# 2. 복붙 프롬프트

---

AI 도구(Claude, ChatGPT, Cursor 등)에 아래 프롬프트를 붙여넣으면, 데이터가 실습 DB에 저장되는 서비스를 만들어 줍니다. **맨 위 `[만들고 싶은 서비스]` 아래에 만들고 싶은 것만 적으면 됩니다.**

```text title="복사해서 AI에게 붙여넣기"
[만들고 싶은 서비스]
(여기에 만들고 싶은 서비스를 자유롭게 적어 주세요. 예: 반 친구들이 서로 응원 메시지를 남기는 방명록)

이 서비스를 만들 때 데이터는 아래 교육용 API를 이용하여 저장되게 해줘. 아래 규칙을 지켜줘.

[교육용 API 주소]
https://dev.wenivops.co.kr/services/fastapi-crud/vibe/{space}

[데이터를 보는 주소]
https://dev.wenivops.co.kr/services/fastapi-crud/vibe/{space}/_sheet
- 저장된 데이터는 이 주소에서 표로 볼 수 있다.
- 서비스를 다 만들면 이 주소를 꼭 알려줄 것.
- 내가 "데이터는 어디서 봐?"라고 물으면 이 주소를 알려줄 것.

[규칙]
1. 주소에 {space}가 그대로 있으면, 서비스에 어울리는 영문 소문자·숫자·하이픈 이름으로
   다른 사람과 겹치지 않게 정해서 두 주소 모두 바꿔 쓸 것. (예: cheer-guestbook-0815)
2. 저장할 데이터 종류와 필드는 서비스에 맞게 네가 정할 것.
   데이터 종류마다 컬렉션 이름을 영어 소문자로 정한다. (예: guestbook, todos)
   컬렉션은 처음 POST하면 자동으로 생긴다.
3. 목록 GET /{컬렉션}  하나 GET /{컬렉션}/{id}
   생성 POST /{컬렉션}  수정 PATCH /{컬렉션}/{id}  삭제 DELETE /{컬렉션}/{id}
   목록 정렬은 ?sort=필드 (내림차순은 ?sort=-필드)
4. 요청과 응답 body는 JSON이다. POST/PATCH에는 'Content-Type: application/json'을 넣는다.
5. id, createdAt, updatedAt은 서버가 만든다. 보내지 않는다. id는 숫자다.
6. 같은 데이터에는 항상 같은 필드 이름을 쓴다. (name과 userName을 섞지 말 것)
7. 에러 응답은 { "detail": "메시지" } 형식이다. 화면에 보여줄 것.
8. API 주소는 코드 맨 위에 상수 하나로 분리할 것.
9. 비밀번호, 주민번호, 카드번호 같은 필드는 만들지 말 것. (서버가 거부한다)
10. 실습용이라 매일 새벽 4시에 데이터가 초기화된다. 목록이 비어 있어도 정상으로 처리할 것.
```

:::div{.callout}
공간 이름을 직접 정하고 싶다면 `{space}` 두 곳을 내 공간 이름으로 바꿔서 붙여넣으세요. 그대로 두면 AI가 서비스에 맞는 이름을 정하고, 완성 후 데이터를 보는 주소를 알려 줍니다.
:::

## 1. 데이터 확인하기

서비스에서 데이터를 저장해 본 뒤, AI가 알려 준 주소(`…/vibe/{space}/_sheet`)를 열면 저장된 데이터를 표로 볼 수 있습니다. 주소를 잊어버렸다면 AI에게 "**데이터는 어디서 봐?**"라고 물어보세요. 자세한 화면 설명은 [시트로 데이터 보기](/eduAPI/vibe/sheet)를 참고하세요.
