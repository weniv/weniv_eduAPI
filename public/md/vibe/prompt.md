# 2. 복붙 프롬프트

---

AI 도구(Claude, ChatGPT, Cursor 등)에 아래 프롬프트를 붙여넣으면, 지금 만들고 있는 웹페이지에 실습 DB가 연결됩니다. **`{space}` 자리에 내 공간 이름**을, 마지막 줄에 **저장하고 싶은 데이터**를 적어서 붙여넣으세요.

```text title="복사해서 AI에게 붙여넣기"
지금 만든 웹페이지에 아래 실습용 백엔드를 연결해서 데이터가 저장되게 해줘.
아래 규칙을 반드시 지켜줘.

[백엔드 주소]
https://dev.wenivops.co.kr/services/fastapi-crud/vibe/{space}

[API 규칙]
1. 컬렉션 이름은 데이터 종류에 맞게 영어 소문자로 정한다. (예: guestbook, todos)
   처음 POST하면 컬렉션이 자동으로 생긴다.
2. 목록 GET /{컬렉션}  하나 GET /{컬렉션}/{id}
   생성 POST /{컬렉션}  수정 PATCH /{컬렉션}/{id}  삭제 DELETE /{컬렉션}/{id}
   목록 정렬은 ?sort=필드 (내림차순은 ?sort=-필드)
3. 요청과 응답 body는 JSON이다. POST/PATCH에는 'Content-Type: application/json'을 넣는다.
4. id, createdAt, updatedAt은 서버가 만든다. 보내지 않는다. id는 숫자다.
5. 같은 데이터에는 항상 같은 필드 이름을 쓴다. (name과 userName을 섞지 말 것)
6. 에러 응답은 { "detail": "메시지" } 형식이다. 화면에 보여줄 것.
7. 백엔드 주소는 코드 맨 위에 상수 하나로 분리할 것.
8. 비밀번호, 주민번호, 카드번호 같은 필드는 만들지 말 것. (서버가 거부한다)
9. 실습용이라 매일 새벽 4시에 데이터가 초기화된다. 목록이 비어 있어도 정상으로 처리할 것.

[저장하고 싶은 데이터]
(예: 방명록 - 이름, 메시지)
```

:::div{.callout}
AI가 코드를 고친 뒤에는 앱에서 데이터를 저장해 보고, [시트로 데이터 보기](/eduAPI/vibe/sheet)에서 실제로 저장되었는지 확인해 보세요.
:::
