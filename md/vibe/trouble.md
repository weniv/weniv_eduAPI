# 4. 자주 막히는 문제

---

## 1. 데이터가 사라졌어요

실습 DB는 **매일 새벽 4시에 모든 데이터가 초기화**됩니다. 같은 공간 이름을 다른 사람도 쓰고 있다면, 그 사람이 지웠을 수도 있습니다. 나만 쓸 법한 공간 이름을 쓰세요.

## 2. 400 에러가 나요

[시트로 데이터 보기](/eduAPI/vibe/sheet)의 최근 요청에서 실패한 요청을 찾고, 응답의 `detail` 메시지를 확인하세요.

| `detail` 메시지 | 해결 방법 |
|---|---|
| body가 올바른 JSON 형식이 아닙니다 | `body: JSON.stringify(데이터)`로 보내고 있는지 확인 |
| body는 { "필드": 값 } 형태의 JSON 객체여야 합니다 | 배열이나 문자열이 아니라 객체 하나를 보내야 함 |
| 개인정보 필드는 실습 DB에 저장할 수 없습니다 | `password` 같은 필드 이름을 빼거나 바꾸기 |
| 공간(space)·컬렉션 이름은 영문·숫자·-·_ 로 40자 이내 | 한글·공백·특수문자를 이름에서 빼기 |

## 3. 404 에러가 나요

- 주소의 `id`가 실제로 있는지 시트에서 확인하세요. 삭제했거나 초기화된 데이터일 수 있습니다.

- `id`는 숫자입니다. AI가 `_id`나 문자열 id를 쓰도록 짰다면 `id`(숫자)를 쓰도록 고쳐 달라고 하세요.

## 4. 시트에 열이 두 개로 나뉘어요

AI가 같은 데이터를 `name`과 `userName`처럼 서로 다른 필드 이름으로 저장한 경우입니다. AI에게 "필드 이름을 name 하나로 통일해줘"라고 요청하세요.

## 5. CORS 에러가 나요

주소가 정확한지 먼저 확인하세요. 특히 `https://`, `/services/fastapi-crud/vibe/` 부분이 빠지지 않았는지 봅니다. 주소가 틀리면 브라우저가 CORS 에러로 보여주는 경우가 많습니다.
